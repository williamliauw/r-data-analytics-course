# R Data Analytics Course

## Deskripsi

- Proyek ini merupakan pembelajaran analisis data menggunakan bahasa pemrograman R dan RStudio. 
- Materi disusun secara bertahap, mulai dari pengenalan R hingga pengolahan data, eksplorasi data, visualisasi, dan interpretasi hasil analisis.

## Tujuan

- Memahami dasar pemrograman R.
- Mempelajari proses pembersihan dan pengolahan data.
- Melakukan exploratory data analysis (EDA).
- Membuat visualisasi data.
- Menghasilkan insight berdasarkan hasil analisis.

## Persyaratan

- R
- RStudio Desktop
- Git

## Progres Pembelajaran

- [x] Pengenalan R dan RStudio
- [ ] Data manipulation
- [ ] Exploratory data analysis
- [ ] Visualisasi data
- [ ] Interpretasi dan insight
